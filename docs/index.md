Dockline is an ESM SDK for Node.js in five independently versioned [packages](/guide/packages). Core provides the shared API; separately installed clients add FTP/FTPS or SFTP. The optional [CLI](/guide/cli) runs everyday file commands from YAML configuration. Start with [installation](/guide/installation) for the SDK, local CLI or global terminal command.
