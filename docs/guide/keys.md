# SSH keys

Dockline Keys has its own [documentation area](/keys/) for users who only need key inspection, conversion and encrypted exports. Install it independently of the transfer SDK.

- [Quick start without file I/O](/keys/quick-start)
- [PPK, OpenSSH and PEM support](/keys/formats)
- [Encrypted conversions](/keys/convert)
- [Encryption and passphrases](/keys/encryption)
- [Public keys](/keys/public-keys)

For SSH/SFTP login, provide supported key contents or a selected key path through the transport authentication options. Format conversion and key-only utilities are documented in Keys.
